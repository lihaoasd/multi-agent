## 2026-09-08 M8 补充：任务系统（乙模式 + D17-①/D18-③）与记忆/检索工具注册

- 需求/问题: 继续整体开发目标：补齐 README「已知边界」中本环境可实现的两项——轻量任务委派（乙模式，含每 Agent 至多 1 in_progress、激活即唤醒、done/terminated 由用户释放）与记忆/检索 Agent 工具（memory_append/memory_search/session_search，D18-② 可见性）。
- 类型: 代码(新建) + 测试
- 改动范围:
  1. `src/application/task/task-service.ts`：tasks.jsonl CRUD。
     - 状态机：todo → in_progress/blocked；blocked → todo；in_progress → done/terminated（终态）。
     - D17-①：每 Agent 至多 1 in_progress（已有则新任务置位 ERR_CONFLICT，可先 todo）；done 需用户确认、terminated 仅用户显式；无自动回退。
     - 乙模式(D15)：assignByAgent=false 时仅 creator=user 可建任务、仅 user 可流转状态（Agent 侧一律 409）。
     - D18-③ 激活即唤醒：置 in_progress → 组合层向受派者 `u_<iid>` 会话注入「请开始执行任务 t_…」消息并触发一轮（测试断言唤醒消息落盘且出现 turn_end）。
     - linkArtifact：任务→code 聚合产物关联锚点（供 code 通道结算调用）。
  2. `src/application/tools/service-tools.ts` + 组合根启动注册：
     - memory_append（own 默认；全局仅 pm_1，D18-②/记忆写权限）；
     - memory_search / session_search（user+meeting 只读可用；session 可见性=本人 u_ 会话 ∪ m_ 会议简化，D18-②）。
  3. `src/application/composition.ts`/`src/server/app.ts`：注入 tasks + registerServiceTools；REST GET/POST /tasks、PATCH /tasks/:tid（state/actor）。
  4. `tests/tasks-m8b.test.ts`：9 用例（todo→in_progress 唤醒回合→done；1 in_progress 槽位冲突→done 释放；terminated 仅 user/终态不可回退/Agent 不可替 done；乙模式 Agent 建任务 409；列表过滤；memory_append own/全局权限；memory_search/session_search 注册可用）。
- 原因: 乙模式任务=用户在 UI 指派→Agent 开工的核心工作流；工具注册让"Agent 可检索"在服务层闭环。
- 行为变化: 可经 REST 建任务并置 in_progress，受派 Agent 自动被唤醒处理一轮；Agent 工具面新增记忆读写与检索（权限/可见性约束生效）。
