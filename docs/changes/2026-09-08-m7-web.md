- 类型: 代码(新建) + 文档
- 改动范围:
  1. `web/`（前端静态 SPA，原生 HTML/CSS/ESM，无构建步骤）：
     - `index.html`：顶栏(新建项目/项目选择)、创建向导(名称+workdir+角色勾选)、三栏布局（左=团队与会话、中=会话窗口与输入、右=审批/会议/产出物/记忆纪要）。

     - `app.js`：项目 CRUD、团队/会话列表、openSession 历史加载、WS(`/ws?projectId=`) 订阅 message.chunk 流式追加与 message.commit 落盘、发送消息、审批(批准/拒绝)、会议(发起/成员接受/请求拍板/拍板答复/结束/查看纪要)、产出物(列表/回退)、全局记忆与纪要展示。

  4. 依赖：`@fastify/static`、`adm-zip`（纯 JS，无原生编译）。
