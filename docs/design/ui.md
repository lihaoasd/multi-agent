# 界面与交互设计 · Agent Haness

> 类别：design · 状态：草稿(待评审) · 决策依据：D19-①⑦⑧、prd FR-25/FR-28/FR-29/FR-30/US-17/18

## 1. 全局信息架构

```
顶部/左侧全局导航
├── 项目        ← 首页默认：项目列表 + 创建项目
├── Agent       ← 系统模板库（含场景标签）
└── 工具        ← 工具包列表
项目页（进入某项目后）
├── 拓扑        ← 2 栏：左画布 + 右三列表
└── 对话        ← 3 栏：左会话切换 + 中会话 + 右三列表
```

- 技术栈：React 18 + Vite（antd 组件 + 画布库，画布候选 React Flow）。
- 主题：浅色（沿用既有浅色主题风格）；中文 UI；无账号体系（本机单用户）。

## 2. 首页三模块

### 2.1 项目模块（默认页）

| 区块 | 内容 |
| --- | --- |
| 项目列表 | 名称/描述/工作目录/创建时间/最近活动；操作：打开、删除（二次确认，仅删运行时数据） |
| 创建项目 | 向导：① 名称与描述 → ② **选择项目目录**（目录浏览器，支持空目录与已有仓库）→ ③ 勾选角色（默认全选 8 个内置模板，可取消）→ ④ 确认创建 |

### 2.2 Agent 模块

- 列表：卡片式，显示模板名称、分类、**场景标签**、职责一句话、默认 loop、默认模型、工具包数量。
- 详情（点卡片）：身份 / loop / **系统提示词只读预览** / 工具（按包分组，标注"挂载但运行期不可用"）/ 模型 / 审批规则。
- MVP 只展示：新建、编辑、复制、停用按钮置灰并提示"配置提交功能后续开放"（见 agent-templates.md §4）。

### 2.3 工具模块

- 列表：包卡片（`name`、`description`、工具数量、最高风险、是否基础包）；**7 个基础包全员必选**标记。
- 展开：包内工具表格（作用 / 风险 / 网络 / 幂等 / 适用会话）。
- MVP 只展示：制作/导入工具包按钮置灰并提示"后续开放"；自定义包区域显示空态说明（见 tool-packages.md §6）。

## 3. 项目页 · 拓扑导航（2 栏）

```
┌──────────────────────────────┬───────────────────────┐
│ 画布（大）                     │ 右栏                   │
│  · Agent 卡片 = 节点           │  · 任务列表            │
│  · 有向边 = 可委派关系          │  · 询问列表            │
│  · 工具栏：添加 Agent / 删除     │  · 审批列表            │
│    自动布局 / 保存              │                       │
└──────────────────────────────┴───────────────────────┘
```

- **节点卡片**：头像/名称/分类、**状态徽标**（`idle`/`working`/`waiting` + `paused` 叠加）、当前任务标题、最近事件时间；右键或卡片菜单：打开会话、暂停、停止、从图中删除。
- **边**：有向箭头，标注最近一次委派时间；选中边可删除；不允许自环与重复边（即时校验并提示）。
- **编辑与保存**：拖拽移动、连线、删除均为本地编辑；"保存"提交全量图（带 `version`）；版本冲突提示"图已被其它页面修改，请刷新后重试"。
- **未保存提示**：离开页面或刷新时提示未保存改动。
- **观测**：`waiting` 节点徽标高亮（有提问或审批待处理）；点击节点自动跳到该 Agent 的会话（切到对话导航）。
- **运行中可编辑**：保存即对未来委派生效，无需暂停（与 orchestration.md §3 一致）。

## 4. 项目页 · 对话导航（3 栏）

```
┌────────────┬────────────────────────────┬───────────────┐
│ 会话切换    │ 会话流                      │ 右栏           │
│ · 各 Agent  │ · 消息（用户/Agent）         │ · 任务列表     │
│   带状态徽标 │ · 工作日志折叠卡（thought/   │ · 询问列表     │
│ · 未读标记  │   tool_call/tool_result/    │ · 审批列表     │
│            │   plan/turn 边界）           │               │
│            │ · 询问卡 / 审批卡（原地处理） │               │
│            │ · 输入框（发送即让该 Agent 开工）│             │
└────────────┴────────────────────────────┴───────────────┘
```

- **会话切换**：每个 Agent 一个会话（MVP 只有 1:1 会话）；显示状态徽标与未读；默认打开最近活跃的会话。
- **工作日志**：会话流中按时间内联展示 Agent 的思考/工具调用/工具结果/计划事件（默认折叠，可展开）；提供"仅看对话 / 显示全部事件"切换与 kind 过滤（对应原始事件时间线）。
- **输入即启动**：在会话输入框发送消息即表示让该 Agent 开始工作（无独立"开始运行"按钮，见 orchestration.md §1）。
- **暂停 / 停止**：会话头右侧按钮——暂停（`paused` 徽标，恢复为"继续"）、停止（二次确认，说明"当前任务将终止并结算未完成改动为快照"）。
- **流式与中断**：回复流式打字；提供"停止生成"（停当前回合输出、队列保留）；未完成回合显示"（未完成）"与补全/重说入口。

## 5. 右栏三列表（拓扑页与对话页共用）

| 列表 | 展示 | 可执行操作 |
| --- | --- | --- |
| 任务 | 标题、状态（`todo`/`in_progress`/`done`/`blocked`/`terminated`）、受派者、**创建者（来源边）**、关联会话、更新时间 | 新建（用户派单，不受边约束）、改状态、终止（带确认）、跳转会话 |
| 询问 | Agent、问题摘要、待答/已答、创建时间 | **原地答复**（选项按钮或文本）、跳转源会话 |
| 审批 | 类型（命令/提交/回退）、摘要与风险、触发者 | 批准 / 拒绝（可填原因）、跳转源会话 |

- 三个列表均有空态文案；`pending` 项带计数角标；**不做**顶部"需要你处理"聚合条（D19-⑦）。
- 列表与画布/会话双向联动：点列表项跳源会话；会话内处理完成后列表实时更新（WS）。

## 6. 关键交互约定

| 场景 | 约定 |
| --- | --- |
| Agent 忙时发送消息 | 入队并提示"正在工作，已排队"；到可中断点后处理 |
| Agent 提问（询问） | 会话内出现询问卡 + 右栏询问列表新增待答项；该 Agent 状态为 `waiting`（其它 Agent 不受影响） |
| 审批命中 | 会话内出现审批卡 + 右栏审批列表新增项；该 Agent 状态为 `waiting` |
| 越权委派（Agent 沿非出边派单） | 工具返回 `ERR_ORCHESTRATION_EDGE`，会话内可见失败说明；画布不产生新边 |
| 实例停用（`enabled=false`） | 画布卡片灰化并标注"已停用"；其边保留但不可派发；会话只读 |
| 空态 | 项目无 Agent：画布提示"从 Agent 库添加成员"；无任务/询问/审批：列表空态；无工具包自定义：模块空态说明 |

## 7. 与接口的对应

| 界面动作 | 接口 |
| --- | --- |
| 首页三模块列表 | `GET /api/projects`、`GET /api/agent-templates`、`GET /api/tool-packages` |
| 画布读取/保存 | `GET|PUT /api/projects/:pid/orchestration` |
| 暂停/恢复/停止 | `POST /api/projects/:pid/agents/:iid/{pause,resume,stop}` |
| 会话流与日志 | `GET /api/projects/:pid/sessions/:sid`、`GET .../log?fromSeq=&kind=` |
| 右栏三列表 | `GET .../tasks`、`GET .../questions`、`GET .../approvals?status=pending` |
| 实时更新 | WS：`agent.state`、`task.updated`、`question.*`、`approval.requested`、`orchestration.updated`、`message.chunk`、`event.appended` |
