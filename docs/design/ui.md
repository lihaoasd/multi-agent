## 1. 全局信息架构

```
顶部/左侧全局导航
├── 项目        ← 首页默认：项目列表 + 创建项目
├── Agent       ← 系统模板库（含场景标签；用户模板可编辑提示词/loop/模型，内置仅默认模型可改、可停用）
├── 模型        ← 模型供应商 + 模型条目（D20；S14 删除「默认路由」）
└── 工具        ← 工具包列表
项目页（进入某项目后）
├── 拓扑        ← 2 栏：左画布 + 右三列表
└── 对话        ← 3 栏：左会话切换 + 中会话 + 右三列表
```

- 技术栈：React 19 + Vite 8 + Ant Design 6（antd 组件 + 画布库，画布候选 React Flow）；实际版本以根 `package.json` 为准。
  - **实现口径（2026-09-15，S7）**：画布**未引入 React Flow**（避免新增重型依赖），改为零依赖 SVG 画布（SVG 箭头 + 绝对定位卡片）：拖拽移动、连线模式点击两端建边、点选/标签删除边、全量保存（带 `version`）、节点暂停/继续与"打开会话"。React Flow 作为 P1 选型保留。
- 主题：浅色（沿用既有浅色主题风格）；中文 UI；无账号体系（本机单用户）。

### 2.2 Agent 模块

- 列表（表格，**S11 起支持行多选**）：`roleId`、名称、分类、**场景标签**、默认 loop、来源（内置/用户）、启用开关、操作；"默认模型"列空值显示「未配置」标签，模型不存在或已停用标"模型不可用"（S11）。
- **批量工具条（S11）**：显示「未配置模型 n 个 · 已选 m 个」；[全选未配置]、[清空选择]、[选择模型] 下拉 + **[一键配置模型]**、**[清空所选默认模型]**（写 `defaultModel: null`）；作用对象即勾选行，内置与用户模板都可被批量写入。
- 行操作：[查看]/[编辑]、**[复制新建]**、[历史]、**[删除]**（仅用户模板 `deletable`；`Popconfirm` 二次确认："删除后不可恢复（被项目成员引用时会被拒绝并点名）"）；内置模板该位置显示"内置"（不可删）。
- 启用开关：**内置模板也可停用/启用**（S11；此前内置一律 `ERR_FORBIDDEN`）；停用只影响此后新建/组队的可选清单，既有实例靠快照继续运行。
- 详情（点卡片/行）：身份 / loop / **系统提示词** / 工具（按包分组，标注"挂载但运行期不可用"）/ 模型 / 审批规则；**内置模板只放开「默认模型」**，其余表单项置灰，顶部提示"内置模板：提示词 / loop 只读，但「默认模型」可改（写入数据目录覆盖，重启不丢）"（S11）。**「工具包」一行恒为 8 个基础包**（S25/D30：8 个基础包全员必装，缺基础包的旧模板/实例在读取时自动补齐；该行只表达"挂载"，能否调用仍看角色工具白名单）。
- **可编辑（FR-35，本轮）**：提示词（多行编辑 + 长度校验 + "预览"按钮，预览与运行期同源拼装）、agent loop（策略下拉 + 参数表单：`maxIterations`/`toolBudget`/`stepModelOverride`）、模型（**仅列出已启用模型条目**，含供应商与能力徽标）；三项对**用户模板**开放，内置模板仅保留"默认模型"。
- **仍只读**：工具与工具包挂载（按钮置灰，提示"工具挂载编辑后续开放"，见 U9 剩余）。
- 保存反馈：字数超限/参数越界/模型未启用即时标红；保存成功提示"已保存；将影响此后新建的实例"。
- **删除被引用保护（S11）**：删除用户模板时若被任何项目实例引用，提示引用清单（项目 / 实例显示名）并拒绝（409），需先从这些项目移除成员。
- **项目内实例覆盖**：项目页 Agent 详情提供 [覆盖配置] 抽屉（同三项 + [恢复为模板快照]）；Agent 处于工作中时提示"下一回合生效（当前回合到可中断点）"。

| 安全提示 | 常驻说明：密钥仅存本机 `data/model-config.json`（不入库）或环境变量；页面与接口只显示掩码 |

- 失败与边界文案：删除被引用的供应商/模型 → 弹出引用清单（模板/实例）并禁用删除按钮；停用被引用模型 → 二次确认 + "运行期将报 ERR_MODEL"；连通性失败 → 展示 `status`/错误摘要（**已脱敏**）与常见排查建议（地址/密钥/网络）。
- 空态：无供应商 → "还没有模型供应商。先添加供应商与模型条目（本机有 Ollama 时可用本地模型）"。

## 3. 项目页 · 拓扑导航（2 栏）

```
┌──────────────────────────────┬───────────────────────┐
│ 画布（大）                     │ 右栏                   │
│  · Agent 卡片 = 节点           │  · 任务列表            │
│  · 有向边 = 可委派关系          │  · 询问列表            │
│  · 工具栏：浏览=编辑/刷新        │  · 审批列表            │
│    编辑=添加 Agent/连线模式/      │                       │
│    刷新/保存/退出编辑            │                       │
└──────────────────────────────┴───────────────────────┘
```

- **运行细条（S15 归位，D25-③）**：挂在**编排图顶部**（不再横跨项目页各标签页）；只列**正在工作**的 Agent——占用者、状态徽标、当前任务、最近 `plan` 状态、队列，并带「停止生成」（停当前回合输出、队列保留）与「停止任务」（终止当前任务，未结算改动先结算为快照）；**无 Agent 在工作时整条不渲染**（原"当前没有 Agent 在工作"空态与"空闲 n｜暂停 m｜队列合计 k"汇总取消）。任务级的终止入口仍在右栏任务列表（把状态改为 `terminated`，规则 17/26）。
- **浏览 / 编辑双模式（S17，D26）**：**默认浏览**——只观测与开会话，不挂任何指针事件（不拖拽、不连线、不删边）；点「编辑」进入**编辑模式**后才出现「添加 Agent / 连线模式 / 保存 / 退出编辑」，此时可拖拽移动、连线、删边、「移出图」。退出编辑时若有未保存改动 → 二次确认（放弃并还原为最近保存版本 / 继续编辑）。
- **节点卡片**：名称、**状态徽标**（`idle`/`working`/`waiting` + `paused` 叠加）、队列数；**浏览模式点卡片任意处 = 打开该 Agent 的会话**（切到「会话」标签并选中它的会话，S17），卡片内保留「暂停 / 继续」运行控制；编辑模式卡片内为「移出图」。
- **连线流程（S17）**：编辑模式下开「连线模式」→ 点起点节点（蓝色高亮）→ 点目标节点成边；连完一条自动清空起点、可继续连下一条；自环与重复边即时拒绝并提示。
- **边**：有向箭头；**点击热区 14px**（可见线仍 2px，选中 3px 加粗变蓝，S18）；编辑模式下有两种删除入口——选中后按工具栏「删除选中边」，或点边标签右侧的 ×；**点画布空白处取消选中**；不允许自环与重复边（即时校验并提示）。
- **编辑与保存**：编辑模式下的拖拽/连线/删除都是本地编辑（标题显示"· 未保存"）；「保存」提交全量图（带 `version`）；版本冲突提示"图已被其它页面修改，请刷新后重试"。
- **未保存提示**：标题标"· 未保存"，退出编辑与编辑模式下「刷新」均先二次确认（放弃 → 还原为最近保存版本）；**浏览器离开/刷新时的提示仍未实现**（P1，见 `plan/development.md` 遗留）。
- **观测**：`waiting` 节点徽标高亮（有提问或审批待处理）；浏览模式点节点自动跳到该 Agent 的会话（切到「会话」标签）。
- **运行中可编辑**：保存即对未来委派生效，无需暂停（与 orchestration.md §3 一致）。

## 4. 项目页 · 对话导航（3 栏）

```
┌────────────┬────────────────────────────┬───────────────┐
│ 会话切换    │ 会话流                      │ 右栏           │
│ · 各 Agent  │ · 消息（用户/Agent）         │ · 任务列表     │
│   带状态徽标 │ · 思考 / 工具调用（含结果）   │ · 询问列表     │
│ · 未读标记  │   直接内联展示（不折叠包装）  │ · 审批列表     │
│            │ · 错误内联；无事件筛选        │               │
│            │ · 询问卡 / 审批卡（原地处理） │               │
│            │ · 输入框（发送即让该 Agent 开工）│             │
└────────────┴────────────────────────────┴───────────────┘
```

- **会话切换（S19）**：每个 Agent 一个会话（MVP 只有 1:1 会话）；**列表项只显示 Agent 名称与状态**——`工作中`（蓝）/ `等待中`（橙）/ `空闲`（灰），暂停时显示 `已暂停`（紫，取自 `GET /agents` 的 `state`+`paused`，与拓扑节点卡片同源）；**不再显示最后一条消息/任务文本与「排队 n」**（队列数在对话页底部状态行与拓扑节点卡片可见）；归档会话另标「已归档」；选中项为浅蓝底 + 蓝边；默认打开最近活跃的会话，**未读标记仍属 P1**。
- **会话流内容（S22，D28）**：按时间内联展示 **对话 + 思考（`thought`）+ 工具调用（`tool_call`，含紧随的 `tool_result`）+ 错误（`error`）**；**不再有事件筛选下拉**，**也不再把非对话事件折叠成"工作日志"卡片**（原"仅看对话 / 显示全部事件（折叠）/ 指定 kind"与折叠包装一并移除）。计划（`plan`）/回合边界/摘要/状态事件**不在会话流展示**（plan 状态在拓扑节点卡片与运行细条可见；原始事件流水仍可经 `GET .../sessions/:sid/log?kind=` 或 Agent 工具 `session_recent` 读取，接口能力不变）。工具调用行标题显示 **`工具调用 <真实工具名>`**、**参数默认折叠**（S28/D33：点击标题展开，展开内容是格式化后的参数 JSON；无参数时不出现空面板）；**工具结果行只显示工具名本身**（S26/D31：不显示结果正文、序号与"工具结果"字样；失败时整行标红并加粗，不加文字）——字段取自事件 payload 的 `tool`/`input`/`summary`（S24 修复了此前按 `name`/`args`/`text` 读取导致"工具名退化成『工具』、参数与结果不显示"的缺陷）。注意：**Agent 自查视图（工具 `session_recent`）仍带结果文本**，那是 Agent 的判断依据，与用户界面口径不同。
- **消息 Markdown 渲染（S23；S27/D32 改用框架）**：**对话消息**用 **`react-markdown` + `remark-gfm`** 渲染——标题、段落、围栏代码块（保留缩进、等宽、可横向滚动）、无序/有序/任务列表、引用、分隔线、**GFM 表格**（带边框，过宽时容器内横向滚动）、删除线、自动链接，行内粗/斜/删除线/行内代码/链接；**不启用 `rehype-raw`（不注入 HTML）**，链接走框架内置 URL 白名单。思考/工具调用/结果/错误**仍是等宽纯文本**。代价：产物 gzip +47 kB（优化项：动态 `import()` 按需加载，见 S27 遗留）。
- **输入即启动**：在会话输入框发送消息即表示让该 Agent 开始工作（无独立"开始运行"按钮，见 orchestration.md §1）。
- **暂停 / 停止**：会话头右侧按钮——暂停（`paused` 徽标，恢复为"继续"）、停止（二次确认，说明"当前任务将终止并结算未完成改动为快照"）。
- **流式与中断（S21/D27 修订）**：回复流式打字；提供"停止生成"（停当前回合输出、队列保留）。**不再有"未完成回合"横幅与三选/补全按钮**——回合被中断这一事实留在会话日志里，由 Agent 在被唤醒时用 `session_recent` 自查，并自行用 `ask_user` 询问用户（询问卡出现在会话流与右栏询问列表）。
- **连接状态提示（S16）**：只在**未连接/重连中**显示一条 warning「实时通道未连接，正在重试…」；连接正常时**不显示任何连接提示**（原「实时通道已连接（事件先落盘后推送）」成功态与附带的开发期说明文案一并移除，`useRealtime` 的重连退避与订阅行为不变）。
- **栏宽与高度（S20）**：左栏会话列表 280px、右栏三列表 340px —— **两栏都可收起**（展开态右上角「‹ 收起」/「收起 ›」，收起态为约 30px 的窄竖条「会话列表 ›」/「‹ 任务·询问·审批」，点击展开；状态写入 `localStorage`，切标签页/刷新后保持），收起后宽度全部让给会话流；**会话流消息区高度改为 `calc(100vh - 350px)`（下限 300px）**，不再写死 420px。实际宽度 = 视口宽 −（全局导航 168 + 内容 padding 48 + 两处 gap 32 + 未收起的两栏），1920 屏全展开约 1050px、1440 屏全展开约 570px、**1440 屏收起两栏约 1190px**。

## 5. 右栏三列表（拓扑页与对话页共用）

| 列表 | 展示 | 可执行操作 |
| --- | --- | --- |
| 任务 | 标题、状态（`todo`/`in_progress`/`done`/`blocked`/`terminated`）、受派者、**创建者（来源边）**、关联会话、更新时间 | 新建（用户派单，不受边约束）、改状态、终止（带确认）、跳转会话 |
| 询问 | Agent、问题摘要、待答/已答、创建时间 | **原地答复**（选项按钮或文本）、跳转源会话 |
| 审批 | 类型（命令/提交/回退）、摘要与风险、触发者 | 批准 / 拒绝（可填原因）、跳转源会话 |

- 三个列表均有空态文案；`pending` 项带计数角标；**不做**顶部"需要你处理"聚合条（D19-⑦）。
- 列表与画布/会话双向联动：点列表项跳源会话；会话内处理完成后列表实时更新（WS）。

## 6. 关键交互约定

| 场景 | 约定 |
| --- | --- |
| Agent 忙时发送消息 | 入队并提示"正在工作，已排队"；到可中断点后处理 |
| Agent 提问（询问） | 会话内出现询问卡 + 右栏询问列表新增待答项；该 Agent 状态为 `waiting`（其它 Agent 不受影响） |
| 审批命中 | 会话内出现审批卡 + 右栏审批列表新增项；该 Agent 状态为 `waiting` |
| 越权委派（Agent 沿非出边派单） | 工具返回 `ERR_ORCHESTRATION_EDGE`，会话内可见失败说明；画布不产生新边 |
| 实例停用（`enabled=false`） | 画布卡片灰化并标注"已停用"；其边保留但不可派发；会话只读 |
| 空态 | 项目无 Agent：画布提示"从 Agent 库添加成员"；无任务/询问/审批：列表空态；无工具包自定义：模块空态说明；无模型供应商：提示"先添加供应商与模型条目（本机有 Ollama 时可用本地模型）" |
| 模型配置失败 | 连通性测试失败展示脱敏错误摘要与排查建议；保存时凭证/地址/模型引用校验不通过即时标红（不落盘） |
| 删除被引用的模型资源 | 供应商/模型被模板或实例引用时禁用删除并列出引用清单；停用被引用模型需二次确认，运行期报 `ERR_MODEL`（不静默换模型） |
| 删除 / 停用 Agent 模板（S11） | 删除仅用户模板且需二次确认，被项目实例引用时拒绝并列出项目/实例清单（409）；内置模板只提供停用（写入数据目录覆盖，重启不丢） |
